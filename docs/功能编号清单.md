# 光律工作台 · 功能编号清单

> 每个用户可见功能一个固定编号（模块码 + 序号，如 `L-07`）。沟通/派工时直接报编号。
> 工作台里点右下角「功能清单」（或 `Shift + F`）可按编号搜索、定位、隐藏/恢复功能。
> 共 374 个功能，登记表唯一事实来源：`frontend/src/features.ts`。
> 号段内出现空号（如 S-02）表示该编号已退役、不再复用；新增功能顺延取本模块下一个空号。
> 点任一功能可查「具体作用 / 被改过几次 / 每次改动的快照」，并可按某次改动回退到之前的整版快照。
